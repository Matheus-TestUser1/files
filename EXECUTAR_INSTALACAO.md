# 🚀 COMO INSTALAR O SISTEMA PDV - INSTRUÇÕES SIMPLES

## ⚡ **INSTALAÇÃO EM 3 PASSOS**

### 📝 **PASSO 1: PREPARAR**
1. **Abra seu Excel** com o sistema atual
2. **Salve o arquivo** (Ctrl + S)
3. **Habilite macros** se solicitado

### 🔧 **PASSO 2: INSTALAR**
1. **Pressione Alt + F11** (abre Editor VBA)
2. **Clique em "Inserir" → "Módulo"**
3. **Cole TODO o código** do arquivo `Instalador_Sistema_Completo_Final.bas`
4. **Pressione F5** ou clique em "Executar"
5. **Digite:** `ExecutarInstalacaoCompleta`
6. **Pressione Enter**

### ✅ **PASSO 3: CONFIRMAR**
- Aguarde as mensagens de progresso
- O sistema criará backup automático
- Será redirecionado para o Dashboard
- Pronto! Sistema instalado!

## 📋 **CÓDIGO RÁPIDO PARA COLAR**

```vba

    Call ExecutarInstalacaoCompleta
End Sub
```
